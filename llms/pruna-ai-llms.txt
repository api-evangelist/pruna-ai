# Pruna AI

> Pruna AI builds Performance Models (P-Series) — optimized, faster and cheaper image and video generation models — delivered through a single HTTP API (P-API), a self-hostable open-source optimization framework, and hosted demos. The P-API exposes ~20 models (text-to-image, image editing, upscaling, virtual try-on, text/image-to-video, avatar/animation/replacement, and LoRA trainers) behind one endpoint, selected via a request header, with async submit/poll/download and an optional synchronous mode.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public OpenAPI and docs.

## API
- [P-API OpenAPI (3.0.3)](https://raw.githubusercontent.com/api-evangelist/pruna-ai/refs/heads/main/openapi/pruna-ai-openapi.yml): Image/video generation. Base URL https://api.pruna.ai. apiKey header `apikey`.
- Operations: createPrediction (POST /v1/predictions), getPredictionStatus (GET /v1/predictions/status/{id}), downloadContent (GET /v1/predictions/delivery/{path}), uploadFile (POST /v1/files).
